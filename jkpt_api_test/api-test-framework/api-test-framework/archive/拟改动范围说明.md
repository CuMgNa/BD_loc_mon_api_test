## 二、`SKILL.md` 拟更新点

### 1) 第2层 `common/` 增补模块

- 新增 `common/allure_assert_util.py` 说明
  - 统一断言入口：`assert_api_result(...)`
  - 成功/失败附件策略（TEXT/JSON）
  - `biz_context` 结构约定（推荐含请求参数、关键中间变量）

- 补强 `common/logger_util.py` 说明
  - `sep/key/print_request/print_response/print_result` 的标准用法
  - 敏感字段脱敏建议

- 补强 `common/captcha_util.py` 说明
  - 验证码识别调用链
  - 识别失败重试建议

### 2) 第3层 `conftest.py` 规范补充

- 增加 `generate_captcha_id()` 约定
- 增加 `auth_token` 验证码登录重试流程说明
- 增加 `auth_headers` 统一构造约定
- 增加 `pytest_runtest_makereport` 失败自动附件策略
- 明确 `clear_data_per_session` 的会话清理职责

### 3) 第4层用例断言模式调整

- 由“手写 if/else 大段断言”调整为“公共断言函数调用模式”
- 推荐模板：
  - 提取 `code/msg`
  - 调用 `assert_api_result(...)`
  - 将个性化参数通过 `biz_context` 传入
